# marginalia

marginalia is an AI-powered study assistant that answers questions using the course PDFs you upload. Organize your materials by subject, ask questions, and pick up past conversations from Chat History.

## How to use marginalia

1. Open [marginalia.my](https://marginalia.my) and sign up or log in.
2. Open the sidebar and select a subject, or use **add new subject** to create one.
3. Click **+** in the chat bar to upload a PDF to that subject. You can also upload from the sidebar.
4. Ask a question about your materials, such as “What are the main ideas in these notes?”.
5. Search **chat history** in the sidebar to reopen a conversation or the new chat icon to start a fresh one.

## Features

- 📄 Upload and process PDF course materials
- 📚 Organize documents by subject
- 💬 Create and maintain persistent chat conversations
- 🧠 Ask context-aware follow-up questions
- 🔎 Retrieve relevant content using semantic vector search
- 🔐 User authentication and data ownership
- 🛡️ PostgreSQL Row Level Security (RLS)
- 🔒 User-scoped document, chat, message, and RAG retrieval
- ♻️ Prevent duplicate document uploads
- 🧹 Clean up incomplete document ingestion when processing fails
- 🧪 Automated testing with Vitest
